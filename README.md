# Marmo Loop

> 組織でも個人でも、常時回り続けるAIエージェントサービス

**Marmo Loop** は、サーバーや個人のマシン上で 24 時間稼働し続け、自律的に「考えて動く」AI エージェントサービスです。

一般的なチャット型 AI（質問 → 回答）とは異なり、自分の置かれた状況を自ら観察し、やるべきことを見つけ、人間の確認を得ながら実行する「学習ループ」として動きます。

```
情報を見る → 状況を理解する → タスクを見つける → 人間に確認する
   → 実行する → 結果を記録する → 次の判断に活かす → また回る
```

詳細は [要件定義書](./要件定義書.md) を参照してください。
